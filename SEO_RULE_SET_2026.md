# StreamToday Blog SEO Rule Set 2026
## Internal Governance Document

## 1. CORE PRINCIPLES

### 1.1 Content Quality First
- Every post must provide genuine value to the reader
- No fluff, filler, or keyword stuffing
- Every claim must be verifiable or clearly stated as opinion
- Original insights > regurgitated information

### 1.2 User Experience Priority
- Content is written for humans first, search engines second
- Scannable structure with clear hierarchy
- Fast loading (<2.5s LCP target)
- Mobile-first design approach

### 1.3 E-E-A-T Compliance
- **Experience:** First-hand knowledge and real examples
- **Expertise:** Demonstrate deep subject matter knowledge
- **Authoritativeness:** Cite credible sources, build trust
- **Trustworthiness:** Transparent, honest, no misleading claims

## 2. KEYWORD STRATEGY

### 2.1 Keyword Selection Criteria
**Must meet ALL of these:**
- [ ] Search volume >100/month (primary), >50/month (secondary)
- [ ] Buyer intent or high informational value
- [ ] Relevant to StreamToday services
- [ ] Achievable competition level
- [ ] UK audience focus (British spelling, GBP pricing)

### 2.2 Keyword Placement Rules
**Primary keyword:**
- Must appear in H1 (front-loaded if possible)
- Must appear in first 100 words
- Must appear in at least one H2
- Must appear in meta title
- Must appear in meta description
- Natural density: 0.5-1.5% (no stuffing)

**Secondary keywords:**
- 3-5 per post
- Distribute across H2s and H3s
- Include in image alt text
- Use in internal link anchor text

### 2.3 Local SEO Keywords
**Priority locations (in order):**
1. Nottingham (primary)
2. Derby
3. Leicester
4. Lincoln
5. Leeds
6. Birmingham
7. Sheffield
8. Manchester

**Format:** "[service] in [location]" or "[location] [service]"

## 3. CONTENT STRUCTURE

### 3.1 Required Elements (Every Post)

**Above the Fold:**
- [ ] Breadcrumb navigation
- [ ] Category tag
- [ ] Publication date (with schema)
- [ ] Reading time estimate
- [ ] Author attribution
- [ ] H1 with primary keyword
- [ ] Compelling hook in first 100 words

**Body Content:**
- [ ] Table of contents (jump links)
- [ ] Minimum 1,500 words (standard), 2,500+ (pillar)
- [ ] H2 every 300-400 words
- [ ] H3 for subsections
- [ ] Bullet points for lists (3+ items)
- [ ] Numbered lists for steps/processes
- [ ] Quote/callout boxes for key insights
- [ ] Internal links (5-8 per post)
- [ ] External links (2-3 to authoritative sources)

**Visual Elements:**
- [ ] Hero image (1200x630px minimum)
- [ ] 3-5 content images (break up text)
- [ ] Alt text on all images (descriptive, keyword-rich)
- [ ] Image captions where relevant

**Below Content:**
- [ ] Strong CTA block
- [ ] Related posts (3-5)
- [ ] Author bio with credentials
- [ ] Social sharing buttons
- [ ] Last updated date

### 3.2 Content Flow Template

```
1. HOOK (100 words)
   - Contrarian statement or surprising fact
   - Promise of value
   - Primary keyword included

2. PROBLEM/CONTEXT (200-300 words)
   - Agitate the pain point
   - Show you understand the reader
   - Build empathy

3. SOLUTION/BREAKDOWN (60% of content)
   - Step-by-step or thematic sections
   - Evidence and examples
   - Practical advice

4. OBJECTIONS (10% of content)
   - Address common concerns
   - Overcome hesitation

5. ACTION STEPS (200 words)
   - Clear next steps
   - Remove friction

6. CTA
   - Book studio session
   - Download lead magnet
   - Contact for consultation
```

## 4. TECHNICAL SEO

### 4.1 Meta Data Standards

**Title Tag:**
- Format: "Primary Keyword | Secondary Keyword - StreamToday Studios"
- Length: 50-60 characters
- Front-load important keywords
- Include brand name

**Meta Description:**
- Length: 150-160 characters
- Include primary keyword
- Include CTA
- Compelling value proposition
- UK spelling

**Example:**
```
Title: Podcast Studio Nottingham | Professional Recording & Live Editing
Description: Book Nottingham's premier podcast studio with live editing. Walk out with finished content. Professional equipment, expert engineers. From £299.
```

### 4.2 URL Structure
- Short and descriptive
- Primary keyword included
- Hyphens for spaces
- No dates (unless news)
- No stop words (a, an, the, etc.)

**Good:** `/blog/podcast-studio-nottingham-live-editing`  
**Bad:** `/blog/2024/03/why-you-should-visit-our-podcast-studio`

### 4.3 Schema Markup (Required)

**Every post must include:**
1. Article schema
2. BreadcrumbList schema
3. Organization schema
4. WebPage schema

**Optional (when applicable):**
- FAQPage schema
- HowTo schema
- VideoObject schema
- Review/Rating schema

### 4.4 Core Web Vitals Targets

**LCP (Largest Contentful Paint):**
- Target: <2.5 seconds
- Hero image must be optimised
- Use next/image with priority
- Preload critical resources

**INP (Interaction to Next Paint):**
- Target: <200 milliseconds
- Minimise JavaScript blocking
- Optimise event handlers

**CLS (Cumulative Layout Shift):**
- Target: <0.1
- Specify image dimensions
- Reserve space for dynamic content
- No layout jumps on load

## 5. AI SEARCH OPTIMISATION (2026)

### 5.1 LLM/RAG Optimisation
- Clear entity definitions (what/who/where)
- Structured data for facts
- Direct answers in first paragraph
- Bullet points for lists
- Tables for comparisons
- Definition lists for terminology

### 5.2 Voice Search Optimisation
- Conversational H2s ("How do I...", "What is...")
- 40-50 word answers for featured snippets
- Question-based subheadings
- Local intent signals ("near me", "in Nottingham")
- Natural language patterns

### 5.3 Semantic SEO
- Topic clusters (pillar + supporting content)
- Related entities and concepts
- Latent semantic indexing (LSI) keywords
- Contextual relevance throughout

## 6. CONTENT QUALITY STANDARDS

### 6.1 Writing Style (Rory Sutherland)
- Contrarian but correct
- Witty, not clever
- Fact-based with interesting statistics
- Anti-equipment, pro-orchestration
- "You have better things to do" messaging
- Calm authority statements
- Practical frameworks, not vague advice

### 6.2 Prohibited Elements
- [ ] Generic AI-sounding openings ("In today's digital landscape...")
- [ ] Keyword stuffing
- [ ] Clickbait headlines that don't deliver
- [ ] US spelling (honour, not honor; colour, not color)
- [ ] Emojis
- [ ] Hyphens in normal writing (use commas or reword)
- [ ] Unsubstantiated claims
- [ ] Corporate jargon
- [ ] Passive voice (use active voice)

### 6.3 Required Elements
- [ ] UK English spelling
- [ ] GBP pricing (£299, not $299)
- [ ] UK locations and references
- [ ] Concrete examples and data
- [ ] Personal anecdotes where relevant
- [ ] Clear CTAs
- [ ] Internal links to booking page
- [ ] Mobile-optimised formatting

---

## 7. INTERNAL LINKING STRATEGY

### 7.1 Priority Pages (Link to These)
1. **Booking page** - Every post, 2+ times
2. **Pricing page** - When discussing costs
3. **Services page** - When mentioning capabilities
4. **Other blog posts** - 3-5 per post, relevant topics
5. **Lead magnets** - Resource downloads

### 7.2 Anchor Text Rules
- Descriptive, not generic ("live editing workflow" not "click here")
- Varied anchor text (don't repeat exact match)
- Natural flow within sentence
- Contextually relevant

### 7.3 Link Placement
- First link in first 200 words
- Mid-content links every 500 words
- CTA link at end of post
- Related posts section

---

## 8. IMAGE OPTIMISATION

### 8.1 Technical Specs
- Format: WebP with JPEG fallback
- Compression: 80-85% quality
- Dimensions: Specified in HTML
- Lazy loading: Native + intersection observer
- CDN delivery: Vercel Edge

### 8.2 SEO Requirements
- Descriptive file names (podcast-studio-nottingham.jpg)
- Alt text: Descriptive, under 125 characters
- Captions: Contextual, engaging
- Schema markup: ImageObject when relevant

### 8.3 Hero Image Standards
- Size: 1200x630px minimum
- Aspect ratio: 16:9 or 4:3
- Subject: Clear focal point
- Overlay: Gradient for text readability
- Branding: Subtle StreamToday watermark

---

## 9. CONVERSION OPTIMISATION

### 9.1 CTA Requirements
**Every post must have:**
- Primary CTA: Book studio session
- Secondary CTA: Download lead magnet or contact
- Tertiary CTA: Share on social

### 9.2 CTA Placement
- Above fold (soft mention)
- Mid-content (contextual)
- End of post (strong CTA block)
- Sticky sidebar (desktop)

### 9.3 CTA Copy Rules
- Action-oriented verbs (Book, Get, Start, Download)
- Benefit-focused (not "Submit", but "Get My Free Guide")
- Urgency without pressure
- Clear next step

## 10. MEASUREMENT & FEEDBACK

### 10.1 Key Metrics (Weekly)
- Organic traffic per post
- Average time on page
- Bounce rate
- Conversion rate (content → booking)
- Keyword rankings (top 10, top 3, #1)
- Core Web Vitals scores

### 10.2 Content Audit (Monthly)
- Update outdated information
- Refresh publish dates
- Add new internal links
- Improve weak content
- Consolidate duplicate topics

### 10.3 Feedback Loop
1. **Measure:** Track metrics weekly
2. **Analyse:** Identify top/bottom performers
3. **Optimise:** Update high-potential content
4. **Replicate:** Double down on winning formats
5. **Eliminate:** Stop creating low-performing content types

## 11. CONTENT CALENDAR TEMPLATES

### 11.1 Standard Post (1,500-2,000 words)
- Target: 1 primary keyword, 3 secondary
- Format: Problem → Solution → Action
- Time to create: 2-3 hours
- Publish: Tuesday or Thursday

### 11.2 Pillar Post (2,500-4,000 words)
- Target: 1 primary keyword, 5-7 secondary
- Format: Comprehensive guide
- Time to create: 4-6 hours
- Publish: Monthly

### 11.3 Local SEO Post (1,200-1,500 words)
- Target: "[service] in [location]"
- Format: City-specific guide
- Time to create: 1-2 hours
- Publish: Weekly
